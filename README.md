# 记工App - Android原生版

一款简洁高效的记工应用，支持本地存储和云同步功能。

## 功能特性

### 📋 记工功能
- **一键记工**：快速记录当天标准工时
- **手动记工**：支持自定义日期、工时、地点、备注
- **加班记录**：支持0.5/1/1.5/2+小时加班
- **饭补记录**：可标记当日是否有饭补
- **工时校验**：超过12小时或不足1小时自动提醒
- **重复检测**：同日期记录自动提醒

### ☁️ 云同步功能
- **双向同步**：本地与Web版服务器实时同步
- **增量同步**：只同步变更数据，节省流量
- **本地优先**：所有操作先写入本地，不阻塞UI
- **冲突解决**：以最后修改时间为准
- **后台同步**：WiFi下自动每30分钟同步
- **手动同步**：随时点击同步按钮立即同步
- **离线支持**：无网络时正常记工，恢复后自动同步
- **状态显示**：首页显示同步状态，待同步记录橙色标记

### 📊 统计功能
- **月度统计**：标准工天数、手动折算、加班小时
- **工资计算**：自动计算应发工资和饭补合计
- **数据对比**：本月vs上月对比分析
- **加班分布**：按加班天数分类统计
- **趋势图表**：近6个月工时趋势折线图
- **地点分布**：本月工作地点占比饼图

### 📅 日历功能
- 月视图日历，有记录的日期显示圆点标记
- 不同颜色区分标准工、加班、手动折算
- 点击日期查看当日详细记录
- 支持下拉刷新触发同步

### ⚙️ 设置功能
- **工时规则**：每日标准工时、加班折算比例
- **工资设置**：日工资、月目标、饭补标准
- **提醒设置**：下班提醒、漏记提醒
- **主题切换**：跟随系统/浅色/深色
- **快捷短语**：自定义常用备注
- **云同步设置**：开启/关闭、服务器地址、账号绑定
- **数据管理**：导出Excel/JSON、清空数据

### 🗑️ 回收站
- 软删除记录，可恢复
- 永久删除功能
- 超过30天自动清理

### 📱 系统集成
- **桌面小组件**：1x1一键记工小部件
- **通知提醒**：下班提醒、漏记提醒
- **生物识别**：指纹/面容解锁保护隐私
- **数据导出**：分享Excel/JSON文件

## 云同步使用说明

### 首次启用云同步
1. 打开"设置"页面
2. 找到"云同步"区域
3. 开启"启用云同步"开关
4. 配置服务器地址（默认 `http://localhost:8080`）
5. 点击"账号绑定"登录Web版账号
6. 登录成功后即可自动同步

### 同步状态说明
- **✅ 已同步**：记录已成功同步到服务器
- **⏳ 待同步**：记录已本地保存，等待同步
- **❌ 同步失败**：同步出现问题，可点击重试
- **🟠 橙色标记**：待同步的记录会显示橙色标记

### 同步设置选项
- **启用云同步**：总开关，关闭后完全本地使用
- **服务器地址**：Web版Docker服务的地址
- **账号绑定**：登录Web版账号
- **移动网络同步**：默认关闭，节省流量
- **同步日志**：查看最近10条同步记录

## 技术栈

- **语言**：Kotlin
- **UI框架**：Jetpack Compose (Material 3)
- **本地数据库**：Room (SQLite)
- **网络框架**：Retrofit + OkHttp
- **后台任务**：WorkManager
- **图表库**：MPAndroidChart
- **Office处理**：Apache POI
- **最低SDK**：API 26 (Android 8.0)
- **目标SDK**：API 34 (Android 14)

## 编译环境

- Android Studio Hedgehog (2023.1.1) 或更高版本
- JDK 17
- Gradle 8.2

## 安装说明

### 方法一：直接安装APK
1. 下载 `记工App-v1.1.0.apk`
2. 在手机上打开APK文件
3. 如果提示"安装被阻止"，请开启"允许安装未知来源应用"
4. 点击安装即可

### 方法二：从源码编译
1. 使用 Android Studio 打开项目目录
2. 等待 Gradle 同步完成
3. 选择 Build > Make Project 或按 Ctrl+F9
4. 选择 Run > Run 'app' 或按 Shift+F10

## 使用说明

### 首次使用
1. 打开应用后，在"设置"中配置：
   - 每日标准工时（默认8小时）
   - 日工资标准
   - 月工时目标
   - 饭补标准
2. 设置提醒时间（可选）
3. 如需云同步，开启并配置服务器地址

### 记工
1. **一键记工**：点击蓝色大按钮，快速记录今天
2. **手动记工**：点击右下角"+"按钮，填写详细信息

### 查看统计
1. 切换到底部"统计"Tab
2. 左右滑动切换不同月份
3. 查看各类统计数据和图表

### 日历查看
1. 切换到底部"日历"Tab
2. 有圆点的日期表示有记工记录
3. 点击日期查看当日详情

## 数据存储

- **本地存储**：所有数据存储在应用私有目录
- **云同步**：可选开启，数据同步到Web版服务器
- **数据导出**：支持导出Excel/JSON进行备份
- **隐私保护**：关闭同步时完全离线，无任何网络请求

## Web版配合使用

本应用需要配合Docker部署的Web版记工服务使用。

### Docker部署Web版服务
```bash
docker run -d \
  --name worklogger-web \
  -p 8080:8080 \
  -v ./data:/app/data \
  worklogger/web:latest
```

详细部署说明请参考Web版项目文档。

### 同步协议
- 服务器地址需可从手机网络访问
- 支持Token认证
- 支持增量同步
- 自动冲突解决
