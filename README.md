# 记工App - Android原生版

一款简洁高效的记工应用，纯单机运行，数据全部存储在手机本地。

## 功能特性

### 📋 记工功能
- **一键记工**：快速记录当天标准工时
- **手动记工**：支持自定义日期、工时、地点、备注
- **加班记录**：支持0.5/1/1.5/2+小时加班
- **饭补记录**：可标记当日是否有饭补
- **工时校验**：超过12小时或不足1小时自动提醒
- **重复检测**：同日期记录自动提醒

### 📊 统计功能
- **月度统计**：标准工天数、手动折算、加班小时
- **工资计算**：自动计算应发工资和饭补合计
- **数据对比**：本月vs上月对比分析
- **加班分布**：按加班天数分类统计
- **趋势图表**：近6个月工时趋势折线图
- **地点分布**：本月工作地点占比饼图

### 📅 日历功能
- 月视图日历，有记录的日期显示圆点标记
- 不同颜色区分标准工、加班、手动折算
- 点击日期查看当日详细记录

### ⚙️ 设置功能
- **工时规则**：每日标准工时、加班折算比例
- **工资设置**：日工资、月目标、饭补标准
- **提醒设置**：下班提醒、漏记提醒
- **主题切换**：跟随系统/浅色/深色
- **快捷短语**：自定义常用备注
- **数据管理**：导出Excel/JSON、清空数据

### 🗑️ 回收站
- 软删除记录，可恢复
- 永久删除功能
- 超过30天自动清理

### 📱 系统集成
- **桌面小组件**：1x1一键记工小部件
- **通知提醒**：下班提醒、漏记提醒
- **生物识别**：指纹/面容解锁保护隐私
- **数据导出**：分享Excel/JSON文件

## 技术栈

- **语言**：Kotlin
- **UI框架**：Jetpack Compose (Material 3)
- **本地数据库**：Room (SQLite)
- **图表库**：MPAndroidChart
- **Office处理**：Apache POI
- **最低SDK**：API 26 (Android 8.0)
- **目标SDK**：API 34 (Android 14)

## 编译环境

- Android Studio Hedgehog (2023.1.1) 或更高版本
- JDK 17
- Gradle 8.2

## 安装说明

### 方法一：直接安装APK
1. 下载 `记工App-v1.0.0.apk`
2. 在手机上打开APK文件
3. 如果提示"安装被阻止"，请开启"允许安装未知来源应用"
4. 点击安装即可

### 方法二：从源码编译
1. 使用 Android Studio 打开项目目录
2. 等待 Gradle 同步完成
3. 选择 Build > Make Project 或按 Ctrl+F9
4. 选择 Run > Run 'app' 或按 Shift+F10

## 使用说明

### 首次使用
1. 打开应用后，在"设置"中配置：
   - 每日标准工时（默认8小时）
   - 日工资标准
   - 月工时目标
   - 饭补标准
2. 设置提醒时间（可选）

### 记工
1. **一键记工**：点击蓝色大按钮，快速记录今天
2. **手动记工**：点击右下角"+"按钮，填写详细信息

### 查看统计
1. 切换到底部"统计"Tab
2. 左右滑动切换不同月份
3. 查看各类统计数据和图表

### 日历查看
1. 切换到底部"日历"Tab
2. 有圆点的日期表示有记工记录
3. 点击日期查看当日详情

## 数据存储

- 所有数据存储在应用私有目录
- 支持完整的数据备份和恢复
- 可导出Excel/JSON进行备份

## 隐私说明

- 纯单机运行，无任何网络请求
- 不收集任何用户信息
- 支持生物识别锁定应用
