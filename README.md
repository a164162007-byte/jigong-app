# 记工App v2.4.2 - Android原生版

一款简洁高效的工地记工应用，纯本地存储，保护隐私。

## ✨ 核心特性

### 📋 记工模块
- **一键记工**：快速记录当天标准工时（9小时=1工）
- **手动记工**：自定义日期、工时、地点、备注
- **自定义工时**：支持半天、自定义小时数等多种选项
- **加班记录**：加班标记，**8小时=1工**（无饭补）
- **饭补记录**：标记当日饭补（30元/天，按工时比例计算）
- **工地名称**：强制输入，支持下拉选择历史工地
- **工时校验**：超12小时或不足1小时自动提醒
- **重复检测**：同日期同类型记录自动提醒
- **批量操作**：长按批量选择删除记录

### 💰 预支工资模块（统计Tab > 预支子页）
- **预支记录**：记录预支工资金额
- **快捷金额**：100/200/500/1000/2000/5000快捷选择
- **月度汇总**：本月预支和累计预支统计
- **编辑/删除**：支持修改和删除
- **时间记录**：精确到小时分钟

### 🛒 垫资模块（统计Tab > 垫资子页）
- **购买记录**：记录工地垫资购买的物品和金额
- **必填项**：购买名称、工地名称、金额
- **可选项**：日期（默认今天）、数量（默认1）、备注
- **月度汇总**：自动统计本月购买支出
- **累计统计**：显示总购买笔数和总金额
- **编辑/删除**：支持修改和删除已有记录
- **软删除**：删除的记录可在回收站恢复
- **历史工地**：自动记录并支持下拉选择

### 📊 统计模块（3个子Tab：统计总览 | 预支 | 垫资）

#### 统计总览
- **月度统计**：标准工天数、手动折算、加班小时
- **工资计算**：自动计算应发工资和饭补合计
- **数据对比**：本月vs上月对比分析
- **加班分布**：按加班天数分类统计
- **趋势图表**：近6个月工时趋势折线图
- **地点分布**：本月工作地点占比饼图
- **月度结算**：生成月度工资结算单（含预支扣除）
- **年度汇总**：支持月/年视图切换，12个月柱状图

### 📅 日历模块
- **月视图**：有记录的日期显示圆点标记
- **颜色区分**：标准工（蓝）、加班（橙）、手动折算（青）
- **日期详情**：点击日期查看当日详细记录

### 🗑️ 回收站
- **软删除**：记录删除后进入回收站
- **恢复功能**：可从回收站恢复记录
- **永久删除**：支持彻底删除
- **自动清理**：超过30天自动清理
- **清空回收站**：一键清空所有已删除记录

### ⚙️ 设置功能

#### 工作设置
- **每日标准工时**：默认9小时
- **加班工时标准**：默认8小时/工
- **饭补金额**：默认30元/天
- **日工资标准**：默认260元/天
- **月工时目标**：默认22小时

#### 外观设置
- **主题模式**：跟随系统 / 浅色 / 深色

#### 数据管理
- **导出JSON**：导出为JSON文件（兼容旧版格式）
- **导入JSON**：从JSON文件导入
- **粘贴导入**：从便签文本批量导入记工记录
- **导出Excel**：导出为Excel表格
- **清除数据**：清除所有数据（不可恢复）

#### 系统设置
- **版本信息**：显示当前版本号
- **检查更新**：从GitHub检查新版本
- **快捷短语**：自定义常用备注

### 📱 系统集成
- **桌面小组件**：1x1一键记工小部件
- **通知提醒**：下班提醒（可设置时间）、漏记提醒
- **生物识别**：指纹/面容解锁保护隐私

## 💡 加班换算规则

| 类型 | 换算标准 | 饭补 |
|------|---------|------|
| 标准工 | 9小时 = 1工 | 有（按工时比例） |
| 加班 | 8小时 = 1工 | 无 |

- 输入加班小时数，自动按8小时/工换算为天数
- 标准工按9小时/天计算
- **加班没有饭补**

## 📱 底部导航栏

记工 → 统计 → 日历 → 设置

> v2.3.8 起精简为4项。统计页内含3个子Tab：**统计总览 | 预支 | 垫资**，预支/垫资功能从独立页面移入统计Tab。

## 🔧 技术栈

- **语言**：Kotlin
- **UI框架**：Jetpack Compose (Material 3)
- **本地数据库**：Room (SQLite) v5（含8个性能索引）
- **图表库**：MPAndroidChart
- **Office处理**：Apache POI
- **网络请求**：OkHttp + Gson（仅用于检查更新）
- **最低SDK**：API 26 (Android 8.0)
- **目标SDK**：API 34 (Android 14)

## 🛠️ 编译环境

- Android Studio Hedgehog (2023.1.1) 或更高版本
- JDK 17
- Gradle 8.2

## 📲 安装说明

### 方法一：直接安装APK
1. 从 [Releases](https://github.com/a164162007-byte/jigong-app/releases) 下载最新APK
2. 在手机上打开APK文件
3. 如果提示"安装被阻止"，请开启"允许安装未知来源应用"
4. 点击安装即可

### 方法二：从源码编译
1. 克隆仓库：`git clone https://github.com/a164162007-byte/jigong-app.git`
2. 使用 Android Studio 打开项目目录
3. 等待 Gradle 同步完成
4. 选择 Build > Make Project 或按 Ctrl+F9
5. 选择 Run > Run 'app' 或按 Shift+F10

## 📖 使用说明

### 首次使用
1. 打开应用后，在"设置"中配置：
   - 每日标准工时（默认9小时）
   - 加班工时标准（默认8小时）
   - 日工资标准（默认260元）
   - 月工时目标（默认22小时）
   - 饭补标准（默认30元）
2. 设置提醒时间（可选）
3. 开始记工吧！

### 记工
1. **一键记工**：点击蓝色大按钮，快速记录今天（9小时标准工）
2. **手动记工**：点击右下角"+"按钮，填写详细信息
   - 工地名称为必填项
   - 可自定义工时（半天4小时、标准9小时等）
   - 加班时选择加班小时数，自动换算天数

### 垫资（统计Tab > 垫资子页）
1. 切换到底部"统计"Tab，滑动到"垫资"子页
2. 点击右下角"+"按钮添加垫资记录
3. 填写购买名称、工地名称、金额（必填）
4. 可选填日期、数量、备注
5. 查看月度汇总和累计统计

### 查看统计
1. 切换到底部"统计"Tab
2. 顶部3个子Tab切换：统计总览 / 预支 / 垫资
3. 左右滑动切换不同月份
4. 查看各类统计数据和图表
5. 点击"结算单"查看月度工资明细

### 日历查看
1. 切换到底部"日历"Tab
2. 有圆点的日期表示有记工记录
3. 点击日期查看当日详情

## 🔒 隐私说明

- **纯本地存储**：所有数据存储在应用私有目录
- **无云同步**：不依赖任何云端服务
- **无广告**：无任何广告推送
- **无收集**：不收集任何用户信息
- **生物识别**：支持指纹/面容解锁保护隐私
- **数据导出**：可导出Excel/JSON进行本地备份

## 📦 数据备份

- 所有数据存储在应用私有目录
- 支持导出Excel/JSON进行备份
- 支持从JSON文件导入恢复
- 应用卸载后数据会丢失，请提前备份
